# Remember Last Search (Odoo 17)

Восстанавливает последний использованный поиск (фильтры, группировки, избранное,
поисковые строки) для каждого action. Работает полностью на клиенте —
localStorage, без серверной части.

## Возможности

- Автоматическое восстановление поиска при повторном открытии action
  (даже после перезагрузки страницы / новой сессии).
- Переключатель **«Запоминать мой поиск»** в меню Favorites — вкл/выкл
  на уровне отдельного action (по умолчанию включено).
- **«Забыть сохранённый поиск»** в меню Favorites — удаляет сохранённое
  состояние и сбрасывает текущий поиск к дефолтам action.
- Не восстанавливает поиск, если action открыт с `dynamic_filters`
  (smart-кнопки, статистика) или с `searchpanel_default_*` — навигация не
  ломается. Поиск с `search_default_*` восстанавливается, если сохранённое
  состояние уже содержит эти дефолтные фильтры активными; если сохранённое
  состояние им противоречит (другие фильтры от smart-кнопки) — пропускается.
- Несовместимое сохранённое состояние удаляется молча, экран не падает.

## Установка

Скопируйте папку `remember_last_search` в свой addons path, обновите список
приложений и установите модуль **Remember Last Search**.

## Как это работает

1. `SearchModel._notify()` (патч) — после каждого реального изменения поиска
   состояние `exportState()` сериализуется в localStorage по ключу
   `remember_last_search:v1:{userId}:{actionId}`.
2. `SearchModel.load()` (патч) — если для action есть сохранённое состояние,
   оно подсовывается в `config.state`; штатная ветка `load()` вызывает
   `_importState()` и поиск восстанавливается целиком.
3. Пункты меню добавляются через реестр `favoriteMenu` — никакие штатные
   view/компоненты не патчатся.

## Диагностика

Модуль пишет в консоль браузера (F12) маркером `[remember_last_search]`:

- `SearchModel patch applied` сразу после загрузки страницы — патч подключён
  (если строки нет — JS модуля не попал в бандл: проверьте, что на сервере
  установлена актуальная копия модуля и список приложений обновлён);
- `localStorage is not available` — localStorage заблокирован (приватный
  режим / запрет cookies в Safari и т.п.), запоминание невозможно;
- `dropped saved search ...` / `could not save search state` — сохранённое
  состояние отброшено из-за повреждения или ошибки импорта (причина в тексте);
- `action <id>: restore skipped (<причина>)` — восстановление намеренно
  пропущено: динамические фильтры (smart-кнопки), `searchpanel_default_*`,
  либо сохранённое состояние противоречит дефолтным фильтрам контекста.
  Контекст действия можно посмотреть в режиме разработчика: Настройки →
  Технические → Действия → ваше действие → поле «Значение контекста».

Ручная проверка: примените группировку, подождите пару секунд, откройте
DevTools → Application → Local Storage — должен появиться ключ
`remember_last_search:v1:{uid}:{id действия}`.

Пункты «Запоминать мой поиск» / «Забыть сохранённый поиск» появляются в меню
Favorites (рядом с избранными фильтрами) только для обычных действий
(не для диалогов и smart-кнопок с `search_default_*`).
