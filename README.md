# Remember Last Search (Odoo 17)

Восстанавливает последний использованный поиск (фильтры, группировки, избранное,
поисковые строки) для каждого action. Работает полностью на клиенте —
localStorage, без серверной части.

## Возможности

- Автоматическое восстановление поиска при повторном открытии action
  (даже после перезагрузки страницы / новой сессии).
- Переключатель **«Запоминать мой поиск»** в меню Favorites — вкл/выкл
  на уровне отдельного action (по умолчанию включено).
- **«Забыть сохранённый поиск»** в меню Favorites — удаляет сохранённое
  состояние и сбрасывает текущий поиск к дефолтам action.
- Не восстанавливает поиск, если action открыт с `search_default_*` /
  `searchpanel_default_*` в контексте или с `dynamic_filters`
  (smart-кнопки, статистика) — навигация не ломается.
- Несовместимое сохранённое состояние удаляется молча, экран не падает.

## Установка

Скопируйте папку `remember_last_search` в свой addons path, обновите список
приложений и установите модуль **Remember Last Search**.

## Как это работает

1. `SearchModel._notify()` (патч) — после каждого реального изменения поиска
   состояние `exportState()` сериализуется в localStorage по ключу
   `remember_last_search:v1:{userId}:{actionId}`.
2. `SearchModel.load()` (патч) — если для action есть сохранённое состояние,
   оно подсовывается в `config.state`; штатная ветка `load()` вызывает
   `_importState()` и поиск восстанавливается целиком.
3. Пункты меню добавляются через реестр `favoriteMenu` — никакие штатные
   view/компоненты не патчатся.
